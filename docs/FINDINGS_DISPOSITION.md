## Decisions not to silently reverse

- **No scheduled regression CI:** only PR Smoke runs tests and actual Chromium; the chart refresh is a separate single-job six-hour data publisher.
- **No automatic incident/README-cache polling:** health and cache audits are manual-only. Real publication failures can still produce normal GitHub Actions failure emails.
- **No full privilege isolation in the lean publisher:** separating write authorization from data fetching would require a separate job/credential or a new architecture.
- **No rewriting signed `v1`:** that legacy alias still identifies `v1.4.1`, while `v1.5.1` is the latest standalone published release. The maintainer has requested updating the Marketplace's default install button **after the checklist is finished**, not as part of this audit.
- **No force-removal of old public chart commits:** historical private contribution fields cannot be guaranteed erased from forks/caches even by rewriting the origin branch.

This closes the **original findings disposition register** (G5-08), not G2-10/G2-11/G2-12 or a claim of perfect cache freshness.
