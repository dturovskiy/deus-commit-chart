## Accepted limitations and what this does not certify

- **All 56 original technical gates** now have implementation evidence or an explicit scope-limited acceptance decision. G2-10/G2-12 operating risks persist without strict token isolation/cache SLA, and G3-08's remaining broader visual/device combinations persist as TD-12. These are tracked in [TECH_DEBT_REGISTER.md](TECH_DEBT_REGISTER.md) and [RELEASE_RISK_DECISIONS.md](RELEASE_RISK_DECISIONS.md), outside the original 65-gate total.
- The public signed legacy major tag `v1` still points to v1.4.1. The latest exact stable Action is **`@v1.5.2`**, independently tested via the remote tag and confirmed as selectable in Marketplace **Use latest version**; see [release report](RELEASE_V1_5_2_REPORT.md). There is no authorized rewrite of the legacy signed major tag.
- A passing PR suite and browser layout test prove defined behavior on the tested runner, not universal compatibility. Personal-device visual observations cover the dark 30d desktop and iPhone GitHub embeds (normal and zoomed); the user accepts the zoom-to-read presentation. Other themes/ranges and device families have actual Chromium automated tests, but no physical human screenshot review, so TD-12 remains.
- The manual GitHub Actions cache probe uses the profile's actual HTML and image URL. Even [three matching snapshots at 24.38/40.21/55.63 seconds](https://github.com/dturovskiy/deus-commit-chart/actions/runs/38146191299) cannot prove a maximum cache TTL or browser/proxy invalidation SLA.
